## 🚀 Следующий шаг:
- [ ] **Обновление бота на удаленном сервере:**
  - Подключиться по SSH к серверу.
  - Перейти в директорию проекта (`cd /opt/Discord_Tickets` или соответствующий путь).
  - Стянуть изменения: `git pull origin main`.
  - Пересобрать и перезапустить контейнер: `docker compose up -d --build`.
  - Проверить статус: `docker compose logs -f bot`.
