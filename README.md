# 🎫 Apple Wallet (.pkpass) to Pixel-Perfect PDF Discord Bot

Высокопроизводительный Discord-бот под ключ для автоматической конвертации билетов Apple Wallet (`.pkpass`) в единый многостраничный Pixel-Perfect PDF, визуально на 100% идентичный отображению билета `eventTicket` на экране iPhone.

---

## ✨ Основные возможности

- **100% визуальное соответствие iPhone Apple Wallet:**
  - Фирменный стек шрифтов Apple (`SF Pro Display`, `SF Pro Text`, `-apple-system`).
  - Пропорции карточки билета, скругления углов (`18px`).
  - Верхний вырез (Notch) по центру карточки.
  - Точная передача цветов (`backgroundColor`, `foregroundColor`, `labelColor`) из `pass.json`.
  - Автоматическая адаптация под темные и светлые темы билетов.
- **Поддержка штрих-кодов и QR:**
  - Генерация векторных QR-кодов высокой четкости (`segno`) в SVG Base64 без потерь качества.
  - Поддержка линейных 1D штрихкодов (`Code 128`) для билетов Etix и концертных операторов.
  - Отображение контрольного номера билета (`altText`).
- **Бизнес-логика и лимиты:**
  - Обработка от 1 до 10 файлов за раз.
  - Объединение нескольких билетов в единый многостраничный PDF-файл (по 1 билету на страницу).
  - Строгая валидация лимита: при превышении 10 файлов бот отклоняет запрос с понятным сообщением: *"Ошибка: Максимальное количество билетов для единовременной обработки — 10 шт."*.
  - Индикация статуса: реакция `⏳` и статус `typing...` во время рендеринга, `✅` по завершении.
  - Именование выходного файла: `tickets_event_YYYY-MM-DD.pdf`.
- **Полная изоляция и чистота:**
  - Вся распаковка `.pkpass` и генерация графики происходит в оперативной памяти (`io.BytesIO`) без создания мусорных файлов на диске.
  - Все зависимости проекта изолированы в виртуальном окружении `.venv`.

## 🚀 Быстрый старт

### 1. Клонирование и настройка Git
Если вы настраиваете проект на новом компьютере, следуйте подробному руководству:
👉 [Инструкция по настройке Git и SSH на новом ПК (GIT_SETUP_GUIDE.md)](./GIT_SETUP_GUIDE.md)

### 2. Создание и настройка Discord-бота

1. Перейдите на [Discord Developer Portal](https://discord.com/developers/applications).
2. Нажмите **New Application**, введите имя (например, `Tickets Converter`) и нажмите **Create**.
3. Перейдите во вкладку **Bot**:
   - Нажмите **Reset Token** и скопируйте полученный токен.
   - Прокрутите вниз до раздела **Privileged Gateway Intents** и **ОБЯЗАТЕЛЬНО ВКЛЮЧИТЕ**:
     - ✅ **Message Content Intent** (необходимо боту для чтения вложений сообщений).
   - Сохраните изменения (**Save Changes**).
4. Перейдите во вкладку **OAuth2** $\to$ **URL Generator**:
   - В блоке **SCOPES** отметьте: `bot`.
   - В блоке **BOT PERMISSIONS** отметьте:
     - `Send Messages`
     - `Attach Files`
     - `Add Reactions`
     - `Read Message History`
   - Скопируйте ссылку внизу, откройте её в браузере и добавьте бота на свой Discord-сервер.

### 3. Конфигурация переменных окружения
Создайте файл `.env` на основе примера:
```powershell
cp .env.example .env
```
Откройте `.env` и укажите ваш токен:
```ini
DISCORD_BOT_TOKEN=ваш_токен_бота_здесь
```

В проект включен готовый `Dockerfile` на базе официального образа Microsoft Playwright с предустановленным Chromium:

## 🗂 Структура проекта

```text
Discord_Tickets/
├── bot.py                # Discord бот, валидация лимитов (1-10) и обработка сообщений
├── parser.py             # Распаковка .pkpass в памяти, парсинг pass.json, генерация QR/1D кодов
├── renderer.py           # Playwright (Chromium), сборка Jinja2 шаблона и рендеринг PDF
├── templates/
│   └── ticket_sheet.html # Pixel-Perfect верстка билета Apple Wallet под печать
├── tests/
│   ├── test_parser.py    # Тесты извлечения данных из pkpass
│   ├── test_renderer.py  # Тесты генерации HTML и рендеринга PDF
│   ├── test_bot_limits.py# Тесты лимитов вложений (0, 1-10, >10)
│   └── generate_samples.py # Генератор тестовых PDF и скриншотов карточек
├── requirements.txt      # Список зависимостей
├── Dockerfile            # Контейнер с Chromium для Playwright
├── docker-compose.yml    # Конфигурация запуска Docker
├── HOST_INSTALLATIONS.md # Реестр установленного ПО на хосте и команды удаления
├── GIT_SETUP_GUIDE.md    # Пошаговая инструкция настройки Git и SSH
└── README.md             # Документация проекта
```
